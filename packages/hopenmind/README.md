# `hopenmind` — brand meta-package

Installing this package pulls in the [Hope 'n Mind Scientific Suite](https://github.com/hopenmind/hopenmind-suite)
(`hopenmind-suite`) as a dependency.

```bash
pip install hopenmind
```

Equivalent to:

```bash
pip install hopenmind-suite
```

The `hopenmind` distribution exists to reserve the brand name on PyPI
and to provide a memorable install command. Import paths live under
each sub-tool (e.g. `from boltz_kernel import ...`).
